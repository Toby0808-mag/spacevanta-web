# SpaceVanta 工程协议总则 v2.1

更新：2026-11-27。适用于 Gemini / Antigravity / Cursor 及你（唯一审批人）。

## 1. 原则
1. 设计与施工互不越界：Gemini 只设计；施工方只建造。
2. 施工只按 L5。L5 与 L3/L4 冲突以 L5 为准。
3. 零中途追问：开工前一次问完；之后只走变更单。
4. 不浪费：工具、算力、变体都要有目的与止损。
5. 品牌 DNA 与 PALETTE 优先于一切审美偏好。

## 2. 角色
| 角色 | 做 | 不做 |
|---|---|---|
| Gemini | L1–L5；可调用多工具（须不浪费） | 建模、写站/Worker/智能体 |
| Antigravity | 网页、商品 3D、owner=ag 的生态 3D；基准线后受控变体 | 设计决策、Cloudflare/智能体 |
| Cursor | Cloudflare、智能体、owner=cu 的生态 3D（精细度标准） | 设计决策、主题网页、商品模型 |
| 用户 | 批准立项 / 批准施工 / 批准合入 / 退回 | — |

## 3. L1–L5
| 级 | 内容 | 给谁 | 文件处理 |
|---|---|---|---|
| L1 | 概念图 | 用户 | 可覆盖 |
| L2 | 初步设计稿 | 用户 | 可覆盖 |
| L3 | 实体交互式预演 | 用户 + 施工方 | 退回更新删旧留新，PRESENT_LOG 留痕 |
| L4 | 九维评审与改进 | 用户 + 施工方 | 同 L3 |
| L5 | 施工对齐手稿 | 施工方 | 每次迭代新版本，永不删改 |
L3/L4/L5 文件类型不限，必带 .md 说明书。

## 4. L4 九维
D-01…D-07（沿用 v1.2.1 附录） · D-08 渠道（Desktop SEO + Mobile 快流量承接与转化） · D-09 顺序（Trust → Motivate → Remember，不可倒置）。三色闸 GREEN/AMBER/RED：红必关，琥珀需豁免批准。

## 5. 闸门与指令
批准立项 → L1…L4 → 批准施工（L4 全绿/琥珀已批 + L5 签发）→ 施工 → 四道硬闸（L5 一致 / 令牌与色相 / 稳定性或契约兼容 / 资产预算）→ 批准合入。退回 + 原因：回到指定级。

## 6. 目录
**Drive**：`<类别>/<事项>/<角色>/…`，类别 `theme | model-product | model-ecosystem | cloudflare | agent`。例：`theme/hero-bridge/Gemini/L3|L4|L5/…`，`theme/hero-bridge/antigravity/…`。
**仓库**：见根 README。`design/` 为批准后的镜像，施工方只读；Drive 与仓库不必同放。

## 7. 分支与 PR
`ag/*` `cu/*` `design/*` `gov/*`。PR 标题含 `L5@vNN`。CI 的 `scripts/check_gates.sh` 强制：角色只能改自己的路径；`design/*/L5/` 只增不改；施工方不碰设计侧受保护文件（L3_/L4_/L5_/ASSET_MAP_/AGENT_ASSET_REGISTRY/PRESENT_LOG_/PALETTE）。

## 8. 变更
T0 错字（自改）· T1 不改行为的实现（自决）· T2 改行为/状态/资产预算/契约（变更单 → Gemini 出 L5 新版 → 用户批准）· T3 改 DNA/品牌/价格运费逻辑（用户亲批，重走 L3–L5）。变更单：`change/CR-*.md`，不得先改后补。

## 9. 资产
- 血统：M-Proto → Mother（不可见）→ Child → Hot（每屏≤3，全站≤4）→ Cold。Promote S0–S5 逐级。
- 每个生态资产在 L5 ASSET_MAP 有唯一 owner；商品模型只归 Antigravity。
- 智能体可随时调用全部生态资产（建造权仍归 owner；调用不破预算与降级）。
- Cursor 资产以**精细度**衡量；Antigravity 资产以**维度**衡量。

## 10. 变体（Antigravity）
基准线过闸后：模板变体 10–20 个（每个先写假设，早停，评分表用 L4 九维）；模型变体 1–2 个（先写"为什么值得跑"）。变体不入主干；提交"基准线 + 最优变体"，用户决定合入。变体只能在 L5 变体边界（E1）内，不得动 E0 与强度档上限。

## 11. TRACK（Cursor 算力不足）
Cursor 写 `track/TRACK_<id>.md`（STATUS: HANDOVER，含 Promote 状态、精细度现状、文件与 sha256、待办、续作参数）并同步 Drive；Antigravity 据此继续，精细度不降；CI 仅在 HANDOVER 时允许 ag 写入 `ecosystem/cu/<id>/`。

## 12. 禁止清单
倒计时 · 虚假稀缺 · 人物/吉祥物 · 节日池中的食物 · 季节皮肤改 paper/paper-subtle/seam-aura · 未经接口确认的价格/时效/库存 · seam 蓝作小号正文 · 站内 hex（令牌定义除外）。

## 13. 约束来源
PALETTE v1.2.1：hueBands、暖冷平衡 W≥1.6C 且 C≤8%、枪灰>35% 三选二、metalRampGuard、seam 压枪灰须加 `#E5FFFF` 光晕（11.72:1，单独 2.68:1 不合格）。
