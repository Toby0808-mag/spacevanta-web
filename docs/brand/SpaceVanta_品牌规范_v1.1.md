## 1. 品牌内核

一句话：**暖纸之上，一条冷色接缝。** 温暖、可信、克制的底（纸与墨），金属的精密（枪灰→银），一条蓝色"接缝"把两者连起来——接缝是品牌唯一的强调语言。

三个关键词：**暖 · 精密 · 克制**。
一切视觉决定用这三个词检验：暖＝纸色面积占主；精密＝金属与接缝出现在结构处；克制＝强调物稀少。

## 2. 色彩

| 令牌 | 值 | 角色 | 规则 |
|---|---|---|---|
| paper | `#FBF7F0` | 主底 | 页面主色，面积最大 |
| paper-subtle | `#F3EFE8` | 次底/卡片/分区 | PALETTE 值（见 §2.1 差异） |
| ink | `#252321` | 正文与标题 | 色相 24–34° |
| gunmetal → silver | `#313540` → `#DBD9DA` | 金属面 | 色相 216–225°；>35% 面积须三选二 |
| seam | `#7DADDE → #E5FFFF → #1D6BFF`（核心 `#1D6BFF`） | 接缝/强调 | 色相 216–221°；线、点、边、大字 |
| seam-aura | `#E5FFFF` | 接缝光晕 | **锁定**；≤3% 面积；不承载文字；接缝压在枪灰上时必须有 |

### 2.1 与已上线主题骨架的差异（需要你定）
主题骨架 0.1.0 的令牌是我当时的默认：`paper-2 #F3ECE0`、`ink-soft #6B655C`、`line #E4DDD0`，与 PALETTE 的 `paper-subtle #F3EFE8` 不同；且骨架里**链接用 seam 蓝**。建议出 0.1.1：paper-2 改为 PALETTE 值；链接文字改 ink + 下划线（原因见 §2.2）。

### 2.2 对比度（本次实算，WCAG）
| 组合 | 比值 | 结论 |
|---|---|---|
| ink / paper | 14.66 | 正文可用 |
| gunmetal / paper | 11.47 | 可用 |
| seam / paper | 4.28 | 仅大字(≥24px 或 ≥19px 粗)与图形；**不够 4.5，不用于小号正文/链接** |
| seam / paper-subtle | 3.98 | 仅图形与大字 |
| paper / seam（反白） | 4.28 | 仅大字按钮文字；小字按钮请用 ink 底 |
| seam / gunmetal | **2.68** | **不合格**，必须加 seam-aura |
| seam-aura / gunmetal | 11.72 | 合格 |
| #7DADDE / paper | 2.21 | 不可作文字或承载含义的线 |
| #E5FFFF / paper | 1.02 | 只做光晕 |
| #6E6964 / paper | 5.08 | 次要文字可用（示例中性灰） |

### 2.3 暖冷纪律
暖冷平衡：暖面积 W ≥ 1.6 × 冷面积 C，且 C ≤ 8%。金属渐变中 `#DBD9DA`(H330) 只在渐变末端 18% 且邻 `#F2F1F0`。**hex 只存在于 PALETTE.json**，其余全部引用令牌。

## 3. 字体与版式
- 暂用 Poppins（标题 600/正文常规）、页宽 1400、按钮圆角 6、商品卡圆角 10。**（待确认：这是主题骨架默认，不是品牌决定）**
- 层级靠字重与间距，不靠色彩；强调色不用于段落文字。

## 4. 接缝语言（品牌唯一强调）
- 形态：细线/点；出现在结构边界（区块分割、卡片边、进度）。
- 动效：绘入（seam-in），时长用 `--svd-dur`；`prefers-reduced-motion` 下直接显示终态。
- 同屏接缝强调 ≤ 一处主、两处辅。

## 5. 资产与形象
- 3D：Hot（每屏 ≤3，全站 ≤4）与 Cold（海报）；Mother 不可见（虚线）。商品模型为主角，生态模型为场景。
- 智能体：G-0 为 ⌀24mm 虚线圈槽位，不拟人化。
- **无人物、无吉祥物、无角色形象。**

## 6. 语气（待确认，草案）
可信、简明、第一人称复数克制使用；价格、运费、时效只陈述接口事实；不用催促语、不用"最后/仅剩"。

## 7. 禁止清单（全站）
倒计时 · 虚假稀缺 · 人物/吉祥物 · 节日池中的食物 · 季节皮肤改 paper/paper-subtle/seam-aura · 未经接口确认的价格/时效/库存 · 把 seam 蓝用作小号正文。

## 8. 季节皮肤
- 只允许改 `--sv-seam / --sv-accent / --sv-season-icon`。
- 皮肤色用于图形/线时，对 paper 的对比度须 ≥ 3.0；做不到的只能作纯装饰，不承载含义。
- 色相不得跨出各自带宽（如 seam 带 216–221°）的例外，需在 L4 里作为琥珀项批准。
- 季节色的具体取值以项目文档 06/13 为准；我未据此重算，**待你确认后在 L4 复测**。
- 总闸：`?sv_season=off` 持久关闭，`?sv_season=on` 恢复；后台可整体关闭。

## 9. 信任信号
运费、时效、退换来自接口，位置固定、措辞固定；不用装饰盖过信息。

## 10. Logo（根据你提供的主图）

文件：`SpaceVanta_logo_主图.jpg`（1080×1080）。
- **构成**：银灰金属的立体字母 **S**（块体，左上角有断裂的切面）+ 分离的 **V**（薄片）。断裂/接合处发蓝光——这就是品牌的"接缝"，Logo 本身就是接缝语言的原型。
- **取色（我从图中取样）**：S 顶面 `#DBD9DA`（与 PALETTE 的 silver 完全一致）；S 暗面 `#6F737F` / `#4B4F5A`（落在 metal 色相 216–225° 内）；接缝光最强处 `#0A6CF5`（接近 seam 核心 `#1D6BFF`）；底 `#FBF6F2`。
- **一个差异**：图中底色 `#FBF6F2` 色相约 27°，略低于 paper 色相带 34–44°（paper 为 `#FBF7F0`）。因此这张图**不要直接贴在站点上**（会与页面纸色有细微色差、并带着烘焙进去的阴影）。
- **需要补的资产（我没有，不编造）**：透明底 PNG/SVG 主标、单色（墨 `#252321`）版、反白版（用于枪灰/墨底）、最小尺寸与留白规则、favicon（SV 简化形）。建议交给 Gemini 走 L1→L5 出规格，再由 Antigravity 做成 3D/矢量交付。
- **使用草案（待确认）**：不改色、不拉伸、不加描边/外发光、不拟人；Logo 周围留白 ≥ S 字母高度的 1/2；接缝蓝光只出现在断裂处，不额外加光晕（光晕仍遵守 seam-aura 规则）；在枪灰/墨底上使用反白或带光晕版本。
- 说明：Logo 的金属渐变包含 H330 的 `#DBD9DA`，属于 PALETTE 的 metalRampGuard 场景——站内再造同类渐变时仍只能出现在渐变末 18%。

## 11. 页面叙事顺序
全站页面与流程遵循 **Trust → Motivate → Remember**：先给可信信息（运费、时效、退换、真实库存/规格），再给行动理由（不用倒计时、不用虚假稀缺），最后给留存路径（保存、复访、订阅）。顺序不得倒置；L4 的 D-09 检查。
