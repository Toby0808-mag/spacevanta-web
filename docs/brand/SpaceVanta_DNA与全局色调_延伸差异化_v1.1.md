# DNA 与全局色调：页面区分与延伸差异化 v1.1

更新：2026-11-27 · 与《品牌规范 v1.0》配套：品牌规范说"是什么"，本文说"在哪个页面用多少、怎么延伸到新模板"。

## 1. 全局色调（所有页面共有，不可延伸）

暖纸底（paper / paper-subtle）+ 墨字（ink）是全站底色。金属与接缝是**强度可调的叠加层**。模板可以多用或少用叠加层，**不能改底色、不能改 seam-aura**。

## 2. 页面强度档（PALETTE dnaRatios 的使用方式）

| 档 | 页面 | 金属（枪灰）面积 | 接缝 | 光晕 | 3D Hot | 季节皮肤 |
|---|---|---|---|---|---|---|
| **高** | Home / Scene / Season | 可 >35%（需三选二） | 主一处 + 辅两处 | 允许 | ≤3/屏 | 全开 |
| **中** | Bundle / MTO | ≤35% | 主一处 | 允许 | ≤2/屏 | 仅 accent 与 icon |
| **低** | PDP / Collection | ≤12%（建议） | 仅边线 | 极少 | 商品模型 1 个 | 仅 icon |
| **最低** | Cart / Checkout | 0（建议） | 仅进度线 | 无 | 0 | 无 |

- 档名对应 PALETTE 的 profiles：`home_scene_season / bundle_mto / pdp_collection / cart_checkout`。表中非"高"档的百分比为我给的建议值，PALETTE 给出的是 alpha/beta/gamma/delta 比例，请 Gemini 在 L5 第 3 节写成对应数值。
- 越往交易深处，DNA 越退场：结算页只保留可读性与信任信号。

## 3. 延伸分级

| 级 | 含义 | 谁能改 |
|---|---|---|
| **E0 锁定** | paper、paper-subtle、seam-aura、hueBands、对比度下限、禁止清单 | 只有你（T3） |
| **E1 档内可调** | 金属面积、接缝位置/数量、3D 数量、动效时长（在档的上限内） | Gemini 在 L5 写明，施工方照做 |
| **E2 季节** | `--sv-seam / --sv-accent / --sv-season-icon` | 季节配置，受 §5 约束 |
| **E3 模板专属** | 新模板自己的布局与组件 | Gemini 设计；施工方只引用令牌 |

## 4. 新模板延伸流程（对应 L1–L5）

1. 在 L1 的 FREEZE 里选**强度档**与季节范围（九项之一）。
2. L2/L3 只使用令牌；预演要能一键切：关闭季节、减少动效、无数据降级。
3. L4 在 D-01…D-07 中核对对比度、色相带、暖冷比、金属面积，写出数值。
4. L5 第 3 节写"令牌清单 + 强度档 + 各令牌允许用在哪"，不写 hex。
5. 施工方只用 `var(--svd-*)`/`var(--sv-*)`。

## 5. 季节皮肤的差异化

- 季节只"换接缝色"，不换底色、不换光晕、不加角色。
- 作用范围随档位收窄（见 §2 末列）。
- 文本不用皮肤色；图形/线用时要求对 paper ≥3.0。我核算过几个常见候选色作参考（**不代表你的季节色**）：

| 候选色 | 对 paper | 对 paper-subtle | 判断 |
|---|---|---|---|
| 深酒红 `#7A1F2B` | 9.55 | 8.90 | 可 |
| 红 `#C0392B` | 5.09 | 4.75 | 可 |
| 蓝灰 `#485D7C` | 6.28 | 5.85 | 可 |
| 玫瑰 `#B8737F` | 3.39 | 3.16 | 勉强，仅图形 |
| 浅玫瑰 `#C98F86` | 2.54 | 2.36 | **不可**承载含义 |
| 琥珀 `#C8943A` | 2.54 | 2.36 | **不可**承载含义 |
| 橙 `#D9822B` | 2.74 | 2.55 | **不可**承载含义 |
| 冰蓝 `#7DADDE` | 2.21 | 2.06 | **不可** |

偏浅的季节色只能做装饰；需要承载含义时，加深或配合形状/文字。

## 5A. 变体与 DNA（Antigravity 变体的边界）

变体可以调：**E1 档内**的金属面积、接缝数量/位置、3D 数量、动效强度、Trust/Motivate/Remember 的落点（顺序不倒置）。
变体不可动：**E0**（底色、光晕、色相带、对比度下限、禁止清单）与**强度档上限**。想把 PDP 做成"高档"属于改档＝T3，不属于变体。
"增加 DNA 权重"的合法范围＝在该页面所属档的上限内上调。

## 5B. 渠道差异（D-08）

- **Desktop**：重 SEO 与信息结构：可抓取文本、标题层级、结构化数据位。DNA 可用得更多（金属/接缝面积在档内取上限）。
- **Mobile**：重快承接与转化：首屏价值+主行动、Trust 信息靠前、3D 数量取下限、动效取弱。DNA 在移动端建议**比桌面低半档**（建议值，待 L4 实测校准）。
