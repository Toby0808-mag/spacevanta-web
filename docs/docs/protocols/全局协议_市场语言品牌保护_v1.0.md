# 全局协议：市场 / 货币 / 语言 / 品牌保护 v1.0

更新：2026-11-28 · 类型：全局协议（Gemini、Antigravity、Cursor 全部适用）
落地时机：**后续跑到"全局链接配置"时统一实施**；本协议先定规则，不立即改主题。

## 1. 市场与货币
- **默认市场：US**；**货币：USD，显示符号 `$`**。
- 含义：没有路径前缀、没有送达国家记录时，默认按 US 取数（市场、运费、节日）。
- 现状差异（待实施清单）：主题骨架 0.1.0 与 `sv-core.js` 的默认市场写的是 `hk`，项目文档 14 也据此描述。**到全局链接配置时统一改为 us**，同时核对：主题设置里的默认市场、运费 Worker 的默认国家、金额格式与 `$` 符号、`sv_ship_to` 的兜底。
- 其他市场（路径前缀）保持现有机制不变，只改"默认"。

## 2. 语言
1. **不做语言学习与收录**：不为 i18n 建翻译记忆/词库，学习记录里也不收录翻译类条目。
2. **后台编辑区固定英文**：编辑器 schema 只提供英文（`en.schema.json`）。主题骨架 0.1.0 里我加的 `zh-hans-cn / zh-hant-tw` 编辑器译文，到全局链接配置时清理。说明：Shopline 后台界面语言可能随账号设置，我没法在这里确认能否强制；以"我们只提供英文标签"为准。
3. **前台使用语言切换器**：访客自行切换；前台文案以 `i18n/en.json` 为主键源。其他语言的文案来源（平台翻译或应用）不在本协议范围，**待你定**。
4. 新增可见文案：先加 `en.json` 键，不再要求同时补其他语言。

## 3. 品牌保护（相关词语不得翻译）
1. 建立**品牌保护词表** `design/BRAND_TERMS.json`（由你与 Gemini 维护；施工方只读）。已确认的词：`SpaceVanta`、`Space Vanta`。**其余词（系列名、产品线名、Season 名称、标语等）我没有资料，请你补。**
2. 词表里的词在**任何语言**下都**不翻译、不音译、不改大小写、不拆写**。适用范围：页面文案、导航、按钮、SEO 标题/描述、图片替代文本、结构化数据、邮件/通知、智能体话术、Logo 字标。
3. 实施规则（到全局链接配置时落地）：
   - 前台输出时给品牌词加不翻译标记（`translate="no"` 与 `notranslate` 类），避免浏览器/翻译应用改写；
   - i18n 文件中的品牌词在所有语言文件里必须与词表**逐字一致**；
   - CI 检查：扫描 i18n、模板与元数据，发现词表词的变体或译文即失败（检查脚本后续随全局链接配置一并提供，**当前没有**）；
   - Gemini 的 L5 在"禁止项"里引用词表，不得设计出需要翻译品牌词的文案位。
4. 语言切换器自身的语言名称用各语言的自称，不属于品牌词。
